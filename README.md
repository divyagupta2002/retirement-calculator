# Retirement calculator

A simple, interactive retirement planner. Adjust your savings, contributions, expenses, and assumptions to see projected retirement funding and withdrawals.

## Run

Open `index.html` in a web browser. No installation or build step is required.

## Use

Edit a value or move its slider. The projection, charts, and annual schedules update automatically. Expand **Breakdown & assumptions** to review the calculation details.

Estimates are illustrative; actual returns and inflation will vary.
